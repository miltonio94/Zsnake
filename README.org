* Description
Wanting to learn about game development I decided to recreate a classic, snake, using Zig and Raylib.
In this project my focus is learning more about Zig's features and the functionality provided by Raylib.
In Znake, the snake does not traverse the plain in a ridgid grid manner, but rather in a smooth manner.
* Building the project
 You need to have Zig installed on your system, but as long as you have it installed all you need to do to build theproject is run
 #+begin_src bash
 zig build
 #+end_src
